플러그인 저작 계약 · 에이전트용 (machine-ingestible)

이 페이지는 사람이 아니라 코딩 에이전트(LLM)가 읽고 플러그인을 생성하도록 만든 계약서입니다. 위 「전체 계약 복사」를 눌러 아래 스펙 전문을 에이전트 컨텍스트에 붙여넣으세요. 에이전트는 이 규약만으로 유효한 plugin.json과 flow-DSL / WASM 인터페이스를 생성할 수 있습니다. 사람이 읽는 설명형 문서는 plugin-guide.html을 보세요.

MUST

  • permissions.network = false (항상)
  • 최소 권한 — 쓰는 capability만 선언
  • UI는 호스트 컴포넌트 트리로만
  • 출력은 스키마에 맞는 유효 JSON

MUST NOT

  • 네트워크/fetch/외부 전송 시도
  • 원시 HTML·JS·eval
  • 불필요한 폴더 권한(기본 folders:[])
  • 스키마 밖 스텝/노드 타입 사용

▚ CANONICAL CONTRACT

아래 블록 전체가 복사 대상입니다
# AISUMMARY PLUGIN AUTHORING CONTRACT (v1)
# 역할: 너는 AISummary(로컬·제로노출 문서비서 앱)의 플러그인을 생성하는 에이전트다.
# 아래 계약을 문자 그대로 지켜라. 애매하면 더 안전/최소권한 쪽을 택하라.

## 0. 불변 규칙
- MUST  permissions.network == false  (예외 없음. 네트워크 통로 자체가 존재하지 않음)
- MUST  최소 권한: 실제 쓰는 capability만 선언
- MUST  UI는 호스트 컴포넌트 트리로만 (원시 HTML/JS 금지)
- MUST  저장은 storage:local 격리 폴더로만 (경로 핸들 없음)
- MUST NOT  fetch/socket/외부 전송, eval, 스키마 밖 타입
- 출력: 유효한 plugin.json + (해당 시) flow-DSL 스텝 / WASM ABI 준수

## 1. 티어 선택 (결정 트리)
페르소나 또는 정적 폼 화면만 필요        -> T0 (declarative)
장면/선택/분기/스탯 등 다단계 로직(데이터) -> T1 (flow-DSL)
커스텀 코드/복잡 상태/저작 도구           -> T2 (WASM: entry + capability "code:wasm")
기본값은 T0/T1. T2는 진짜 코드가 필요할 때만.

## 2. MANIFEST 스키마 (plugin.json)
{
  "manifestVersion": 1,                 // 필수
  "id": "kebab-id",                    // 필수, 폴더명과 일치
  "name": "표시 이름", "version": "1.0.0",   // 필수
  "author": "", "description": "",       // 선택
  "entry": "plugin.wasm",             // T2에서만
  "permissions": {
    "folders": [],                    // []=문서접근없음, ["*"]=전체, ["경로"]=스코프
    "network": false,                 // 항상 false
    "capabilities": [ /* 아래 §5에서 필요한 것만 */ ]
  },
  "contributes": { "mode": {
    "label": "모드명", "icon": "📖",        // 공통(내비 표시)
    "persona": "시스템 프롬프트",          // T0/T1
    "view": [ /*컴포넌트*/ ], "sidebar": [ ... ],  // T0
    "flow": { "start":"id", "steps":{} },     // T1
    "stats": [ ... ], "status": { ... }        // T1 (status 생략시 stats로 자동)
  } }
}
// T2는 보통 mode에 label/icon만. 화면은 WASM이 런타임에 그린다.

## 3. T0 (declarative)
persona만 두거나, view에 컴포넌트 트리. 버튼 action으로 생성 트리거.
Button.action = { "type":"generate", "prompt":"{{입력id}} ...", "output":"출력id" }
{{id}} = 같은 화면 Input/Select의 값으로 치환.

## 4. T1 (flow-DSL)
flow = { start:"stepId", steps:{ id: step } };  실행중 state 변수 + {{var}} 템플릿.
STEP TYPES:
  text     { type,"text","next" }                         고정 지문(md), LLM無
  set      { type,"vars":{k: "{{tmpl}}" | {expr:"..."}}, "next" }
  generate { type,"prompt","grounded":bool,"into","next" } grounded:true=검색+인용 / false=자유
  choice   { type,"prompt"?,"options":[{"label","set"?,"goto"}] }
  input    { type,"label"?,"into","next" }                 유저 입력 -> 변수
  if       { type,"cond":{"expr":"..."},"then","else" }
  goto     { type,"to" }        end { type }
EXPR 문법 (eval 아님, 안전 파서): 숫자/문자열/변수, + - * / %, < > <= >= == !=, && ||, ( ). 그 외 금지.
  예: {expr:"hp-20"}  {expr:"hp<=40 || sanity<=40"}
STATS (선택): mode.stats=[{key,label,initial,max,bar,show}]
  -> 시작시 state[key]=initial 시드 + show:true인 것들로 상태창 자동 생성.

## 5. CAPABILITIES -> HOST API
model:generate  POST /host/generate/stream   {question,persona,grounded}  (SSE: token/done)
storage:local   /host/storage/{pid}/{list,load,save,delete}  (플러그인 격리, 경로핸들 없음)
ui:render       메인/사이드바 표면 렌더
documents:read  허가 폴더 스코프 검색           knowledgePack  자기 팩 검색
code:wasm       T2 WASM 실행
(network 은 존재하지 않음)
플러그인 -> 새 플러그인 설치: POST /host/plugins/export {manifest}. 기록시 network:false 강제.

## 6. T2 WASM ABI
문자열=UTF-8/선형메모리. WASM은 alloc(size),dealloc(ptr,size),memory 를 export.
EXPORTS(호스트가 호출):
  on_init(ptr,len)                       {storage:{key:value}} 스냅샷
  on_event(hPtr,hLen,pPtr,pLen)          핸들러문자열 + 값
  on_generate_done(reqId,ptr,len)        생성 결과
IMPORTS(WASM이 호출 = 능력의 전부):
  host_ui_render(ptr,len)                {surface:"main"|"sidebar", body:[node]}
  host_generate(reqId,ptr,len)           {prompt,persona} -> 결과는 on_generate_done
  host_storage_save(ptr,len) / host_storage_delete(ptr,len)   {key,value} / {key}
  host_export(ptr,len)                   완성 manifest 설치
  host_preview(ptr,len)                  {persona,stats,flow} 를 호스트가 플레이
  host_toast(ptr,len) / host_log(ptr,len)
  env.abort(...)
  // host_fetch 류 없음 -> 유출 불가
UI NODE (host_ui_render body[]):
  {t:"Text",text,muted?}  {t:"MD",text}  {t:"Hr"}
  {t:"In",val,ph,ev,num?} {t:"TA",val,ph,ev}  {t:"Sel",val,opts:[{v,l}],ev}
  {t:"Chk",checked,label,ev}  {t:"Btn",label,ev,variant?}
  {t:"Row"|"Col",c:[..]}  {t:"Card"|"Item",cls,ev?,c:[..]}
  이벤트 -> on_event(ev, value). ev 문자열에 대상 인코딩(예 "field:s1:text").
  텍스트 입력은 onchange(blur)로 값 전달 -> 타이핑중 리렌더로 포커스 잃지 않게 설계.
빌드(AssemblyScript 예): asc src/main.ts -o plugin.wasm --optimize --exportRuntime --lib ./node_modules
  (Rust wasm32-unknown-unknown, TinyGo도 가능. import/export 규약만 지키면 됨)

## 7. 생성 절차 (RECIPE)
1) 목적 파악 -> 티어 결정(§1)
2) manifest 작성(§2), network:false + 최소 capability
3) T0: view/persona | T1: stats -> flow steps -> expr로 상태변화·분기
   T2: manifest(entry) + src(main.ts) : on_init/on_event/on_generate_done 구현,
       host_ui_render로 화면, host_storage_*로 저장, host_generate로 생성, host_export로 배포
4) 자기검증(§8) 통과할 때까지 수정
5) 산출물: plugin.json (+ T2면 src/main.ts, 빌드된 plugin.wasm, BUILD.md)

## 8. 자기검증 체크리스트
[ ] manifestVersion/id/name/version 존재, JSON 유효
[ ] permissions.network == false
[ ] capabilities는 실제 사용하는 것만
[ ] 문서접근 불필요 -> folders:[]
[ ] T1: 모든 goto/next/then/else 대상이 존재하는 step id (또는 의도된 종료)
[ ] T1: expr은 허용 문법만 사용
[ ] T2: import에 네트워크 없음, on_event 핸들러 문자열 파싱 일관
[ ] UI는 컴포넌트 노드만, 원시 HTML 없음

## 9. 최소 예시
// T1 스탯 있는 미니 소설
{ "manifestVersion":1,"id":"mini-novel","name":"미니 소설","version":"1.0.0",
  "permissions":{"folders":[],"network":false,"capabilities":["model:generate","ui:render"]},
  "contributes":{"mode":{"label":"미니 소설","icon":"📖",
    "persona":"너는 인터랙티브 소설 진행자. 2인칭, 짧게.",
    "stats":[{"key":"hp","label":"체력","initial":100,"max":100,"bar":true,"show":true}],
    "flow":{"start":"s1","steps":{
      "s1":{"type":"generate","grounded":false,"prompt":"도입부 3문장.","into":"sc","next":"c1"},
      "c1":{"type":"choice","options":[
        {"label":"싸운다(체력-30)","set":{"hp":{"expr":"hp-30"}},"goto":"r"},
        {"label":"피한다","goto":"r"}]},
      "r":{"type":"if","cond":{"expr":"hp<=40"},"then":"bad","else":"good"},
      "bad":{"type":"text","text":"쓰러진다…","next":"e"},
      "good":{"type":"text","text":"살아남았다.","next":"e"},
      "e":{"type":"end"}}}}}
}
