T2 WASM 프로그래밍 계약 · 에이전트용

AssemblyScript + SDK
이 페이지는 코딩 에이전트(LLM)가 읽고 T2(WASM) 플러그인을 AssemblyScript + 제공 SDK로 직접 코딩하도록 만든 계약서입니다. 위 「전체 계약 복사」로 스펙 전문을 에이전트 컨텍스트에 붙여넣으세요. 매니페스트/티어 등 상위 계약은 plugin-guide-agent.html, 사람용 코딩 설명은 plugin-guide-programming.html을 보세요.

MUST

  • UI는 SDK 빌더(ui.Text/ui.Button…)로만 조립
  • alloc/dealloc re-export + 3개 lifecycle export
  • 매니페스트 network:false + code:wasm
  • 저장은 ui.storage.*로만

MUST NOT

  • host_* 직접 호출 / 손수 JSON 문자열 조립
  • 텍스트 입력 핸들러에서 render() (포커스 튐)
  • 네트워크/fetch, eval
  • SDK 밖 UI 노드 타입

▚ CANONICAL CONTRACT

아래 블록 전체가 복사 대상 (예제 소스 포함)
# AISUMMARY T2 (WASM) PLUGIN — ASSEMBLYSCRIPT + SDK CONTRACT (v1)
# 역할: 너는 AISummary T2 플러그인을 AssemblyScript로, 제공된 SDK(aisummary.ts)를 써서 생성하는 에이전트다.
# UI는 SDK 빌더로만 조립한다. host_* 직접 호출이나 손수 JSON 문자열 조립은 금지.

## 0. 불변 규칙
- MUST  permissions.network == false, capabilities 에 "code:wasm" 포함
- MUST  alloc/dealloc 를 re-export, on_init/on_event/on_generate_done 를 export
- MUST  UI 는 SDK 빌더(ui.Text/ui.Button/ui.Row/...)로만 만들고 ui.renderMain/renderSidebar 로 그린다
- MUST  저장은 ui.storage.* 로만 (격리 폴더)
- MUST NOT  host_* 직접 호출, 손수 JSON 문자열 조립, 네트워크/fetch, eval, SDK 밖 노드 타입
- MUST NOT  텍스트 입력(Input/Textarea) 핸들러에서 render() 호출 (포커스 튐 → 상태만 갱신)

## 1. 파일 & 의존성
plugin.json  (entry:"plugin.wasm", capabilities:["code:wasm",...])
src/main.ts  (너의 코드)      aisummary.ts (SDK, 그대로 포함)     plugin.wasm (빌드 산출물)
deps: npm i assemblyscript assemblyscript-json

## 2. SDK API   // import * as ui from "./aisummary"; import { Node } from "./aisummary";
UI 빌더 -> Node 반환:
  ui.Text(text, muted=false)   ui.Markdown(text)   ui.Divider()
  ui.Input(value, ph, ev, num=false)   ui.Textarea(value, ph, ev)
  ui.Select(value, [ui.opt(v,l), ...], ev)   ui.Checkbox(checked, label, ev)
  ui.Button(label, ev, variant="")   // variant: "primary"|"mini"|"mini danger"|"ai"|""
  ui.Row([Node])  ui.Col([Node])  ui.Card(cls,[Node])  ui.Item(cls, ev, [Node])
렌더: ui.renderMain([Node])  ui.renderSidebar([Node])   // 또는 ui.render(surface,[Node])
호스트 능력:
  ui.toast(msg)  ui.log(msg)
  ui.generate(reqId, prompt, persona)                // 결과는 on_generate_done(reqId,...)로
  ui.storage.saveStrings(key, string[])  ui.storage.saveString(key, s)
  ui.storage.saveJson(key, valueJson)    ui.storage.remove(key)
  ui.exportPlugin(manifestJson)          ui.preview(specJson)
라이프사이클 헬퍼:
  ui.alloc(size) ui.dealloc(ptr,size) ui.readStr(ptr,len)
  ui.initStorage(ptr,len) -> JSON.Obj                 // on_init 에서 저장소 스냅샷
  ui.event(hp,hl,pp,pl) -> Ev                          // on_event 에서
  Ev: .cmd(첫 토큰)  .arg(i)  .argInt(i)  .value(입력값)
타입: class Node · class Opt / ui.opt(v,l) · class Ev

## 3. 필수 EXPORT 스켈레톤
import { JSON } from "assemblyscript-json/assembly";
import * as ui from "./aisummary";
import { Node } from "./aisummary";
export function alloc(s: i32): usize { return ui.alloc(s); }
export function dealloc(p: usize, s: i32): void { ui.dealloc(p, s); }
export function on_init(ptr: usize, len: i32): void { const store = ui.initStorage(ptr, len); /* load */ render(); }
export function on_event(hp: usize, hl: i32, pp: usize, pl: i32): void { const e = ui.event(hp,hl,pp,pl); /* dispatch e.cmd */ }
export function on_generate_done(reqId: i32, ptr: usize, len: i32): void { const t = ui.readStr(ptr, len); /* apply */ render(); }

## 4. 이벤트 규약
- ev 문자열에 커맨드+인자 인코딩: "add" · "del:3" · "field:s1:text"
- e.cmd = 첫 토큰, e.argInt(0) = 첫 인자(정수), e.value = 입력/선택/체크 값
- 텍스트 입력 핸들러: 상태만 저장하고 render() 하지 말 것
- 버튼/셀렉트/체크박스 핸들러: 상태 변경 후 render() 호출

## 5. generate / storage 패턴
generate: ui.generate(1, prompt, persona);  결과 -> on_generate_done(1, ptr,len) 에서 ui.readStr로 수신
storage 저장: ui.storage.saveStrings("notes", arr)
storage 로드: on_init 에서 ui.initStorage(...).getArr("notes"); 각 항목 (<JSON.Str>a[i]).valueOf()

## 6. 매니페스트 (plugin.json)
{ "manifestVersion":1, "id":"ai-notes", "name":"AI 메모", "version":"1.0.0", "entry":"plugin.wasm",
  "permissions":{ "folders":[], "network":false, "capabilities":["code:wasm","model:generate","ui:render","storage:local"] },
  "contributes":{ "mode":{ "label":"AI 메모", "icon":"💡" } } }

## 7. BUILD
asc src/main.ts -o plugin.wasm --optimize --exportRuntime --lib ./node_modules
PATCH: node_modules/assemblyscript-json/assembly/JSON.ts 의 Str.stringify() 가 제어문자를
  \n \r \t \b \f \uXXXX 로 이스케이프하도록 수정(라이브러리 버그). SDK의 esc()/storage.* 는 이미 안전.

## 8. 자기검증 체크리스트
[ ] network:false, capabilities에 code:wasm
[ ] alloc/dealloc export + on_init/on_event/on_generate_done export
[ ] UI는 SDK 빌더만 사용, host_* 직접호출/손수 JSON 없음
[ ] 텍스트 입력 핸들러에 render() 없음
[ ] 이벤트 파싱 일관: e.cmd / e.argInt(i) / e.value
[ ] 저장은 ui.storage.* 로만
[ ] Node 하네스로 on_init/on_event/on_generate_done 구동 확인(아래 §10)

## 9. 완전한 예시 — src/main.ts (컴파일·검증됨)
import { JSON } from "assemblyscript-json/assembly";
import * as ui from "./aisummary";
import { Node } from "./aisummary";
export function alloc(s: i32): usize { return ui.alloc(s); }
export function dealloc(p: usize, s: i32): void { ui.dealloc(p, s); }
let notes: string[] = []; let draft: string = ""; let output: string = "";
function render(): void {
  const main: Node[] = [
    ui.Text("💡 AI 메모"),
    ui.Textarea(draft, "메모를 입력…", "draft"),
    ui.Row([ ui.Button("＋ 저장", "add", "primary"), ui.Button("✨ AI로 요약", "summarize") ]),
  ];
  if (output.length > 0) main.push(ui.Markdown(output));
  ui.renderMain(main);
  const side: Node[] = [ ui.Text("메모 " + notes.length.toString() + "개", true) ];
  for (let i = 0; i < notes.length; i++) {
    const preview = notes[i].length > 40 ? notes[i].substring(0, 40) : notes[i];
    side.push(ui.Card("note-item", [ ui.Text(preview), ui.Button("삭제", "del:" + i.toString(), "mini danger") ]));
  }
  ui.renderSidebar(side);
}
export function on_init(ptr: usize, len: i32): void {
  const store = ui.initStorage(ptr, len); notes = [];
  const arr = store.getArr("notes");
  if (arr != null) { const a = arr.valueOf(); for (let i = 0; i < a.length; i++) notes.push((<JSON.Str>a[i]).valueOf()); }
  render();
}
export function on_event(hp: usize, hl: i32, pp: usize, pl: i32): void {
  const e = ui.event(hp, hl, pp, pl);
  if (e.cmd == "draft") { draft = e.value; return; }
  if (e.cmd == "add") {
    if (draft.length == 0) { ui.toast("내용을 입력하세요"); return; }
    notes.push(draft); draft = ""; ui.storage.saveStrings("notes", notes); ui.toast("저장됨"); render(); return;
  }
  if (e.cmd == "del") {
    const idx = e.argInt(0); const n: string[] = [];
    for (let k = 0; k < notes.length; k++) if (k != idx) n.push(notes[k]);
    notes = n; ui.storage.saveStrings("notes", notes); render(); return;
  }
  if (e.cmd == "summarize") {
    if (notes.length == 0) { ui.toast("메모가 없습니다"); return; }
    output = "…"; render();
    ui.generate(1, "다음 메모들을 3줄로 요약해줘:\n- " + notes.join("\n- "), "너는 간결한 메모 정리 도우미야."); return;
  }
}
export function on_generate_done(reqId: i32, ptr: usize, len: i32): void { output = ui.readStr(ptr, len); render(); }
