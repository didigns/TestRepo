플러그인 프로그래밍 가이드 AssemblyScript

T2(WASM) 플러그인을 AISummary SDK로 직관적으로 작성하는 방법. 문자열 조립·메모리 마샬링은 SDK가 감추고, 당신은 Text() · Button() · render()만 씁니다.

이 문서는 코드를 짜는 사람을 위한 것입니다. 아키텍처 개념은 plugin-guide.html, 에이전트용 계약은 plugin-guide-agent.html을 보세요.

1. 왜 AssemblyScript인가

WASM은 Rust·TinyGo·C 등 여러 언어로 만들 수 있지만, 이 앱에는 AssemblyScript 하나를 추천합니다.

  • TypeScript 문법 — 앱 프론트가 이미 JS/TS라 학습 곡선이 거의 없습니다.
  • 가벼운 툴체인 — npm i assemblyscript 한 줄. 별도 컴파일러 설치·크로스툴체인 불필요.
  • 작은 바이너리 — 예제 플러그인이 30KB대.
  • 검증된 경로 — 앱의 소설 메이커가 AssemblyScript로 작성되어 있습니다.

2. 설치 & 프로젝트 구조

# 툴체인 + JSON 라이브러리
npm i assemblyscript assemblyscript-json
my-plugin/
├─ plugin.json          # 매니페스트 (entry: "plugin.wasm")
├─ src/main.ts          # 당신의 플러그인 코드
├─ aisummary.ts         # SDK (이 파일을 그대로 넣으세요)
└─ plugin.wasm          # 빌드 산출물

plugin.json은 T2 매니페스트입니다. entry와 code:wasm 능력을 선언하세요.

{
  "manifestVersion": 1, "id": "ai-notes", "name": "AI 메모", "version": "1.0.0",
  "entry": "plugin.wasm",
  "permissions": { "folders": [], "network": false,
    "capabilities": ["code:wasm", "model:generate", "ui:render", "storage:local"] },
  "contributes": { "mode": { "label": "AI 메모", "icon": "💡" } }
}

3. SDK 개요

SDK 없이 직접 짜면 UI가 문자열 조립이라 읽기 힘듭니다. SDK는 이걸 선언적 함수로 감쌉니다.

✗ SDK 없이 (raw)
main += "," + node("Row",
  q("c")+":["+node("Btn",
    q("label")+":"+q("저장")+
    ","+q("ev")+":"+q("add")+
    ","+q("variant")+":"+q("primary"))
  +"]");
✓ SDK로
ui.Row([
  ui.Button("저장", "add", "primary"),
])

임포트는 이렇게 시작합니다. 마샬링 함수 두 개만 re-export 하면 나머지는 SDK가 처리합니다.

import * as ui from "./aisummary";
import { Node } from "./aisummary";

// WASM이 export 해야 하는 마샬링 함수 (한 줄씩 위임)
export function alloc(size: i32): usize { return ui.alloc(size); }
export function dealloc(ptr: usize, size: i32): void { ui.dealloc(ptr, size); }

UI 빌더

모든 빌더는 Node를 반환하고, 컨테이너는 Node[]를 받습니다. 마지막에 render*로 표면에 그립니다.

함수설명
Text(text, muted?)텍스트(muted=회색 보조)
Markdown(text)마크다운 렌더
Input(value, ph, ev, num?)한 줄 입력(num=숫자)
Textarea(value, ph, ev)여러 줄 입력
Select(value, [opt(v,l)…], ev)드롭다운. opt(value,label)로 항목
Checkbox(checked, label, ev)체크박스
Button(label, ev, variant?)버튼. variant: primary/mini/mini danger/ai
Row([...]) · Col([...])가로/세로 배치
Card(cls, [...])카드 컨테이너(클래스 지정)
Item(cls, ev, [...])클릭 가능한 목록 항목
Divider()구분선
renderMain([...]) · renderSidebar([...])메인/사이드바 표면에 그리기
텍스트 입력(Input/Textarea)의 ev는 포커스를 잃을 때(onchange) 값을 돌려줍니다. 그래서 텍스트 이벤트 핸들러에서는 다시 render()하지 마세요(타이핑 중 리렌더 → 포커스 튐). 상태만 갱신하고, 구조가 바뀌는 버튼/셀렉트에서만 다시 렌더하세요.

호스트 능력

함수설명
toast(msg) · log(msg)알림 / 디버그 로그
generate(reqId, prompt, persona)로컬 LLM 호출. 결과는 on_generate_done(reqId, …)으로 도착
storage.saveStrings(key, string[])문자열 배열 저장(가장 흔함)
storage.saveString(key, value)문자열 하나 저장
storage.saveJson(key, valueJson)직렬화된 JSON 값 저장(고급)
storage.remove(key)키 삭제
exportPlugin(manifestJson)완성 매니페스트를 새 플러그인으로 설치
preview(specJson){persona,stats,flow}를 호스트 런타임이 플레이

라이프사이클

플러그인은 세 함수를 export합니다. SDK가 파싱을 도와줍니다.

export 함수SDK 헬퍼
on_init(ptr,len)ui.initStorage(ptr,len) → 저장소 JSON.Obj
on_event(hp,hl,pp,pl)ui.event(...) → Ev{ cmd, arg(i), argInt(i), value }
on_generate_done(reqId,ptr,len)ui.readStr(ptr,len) → 결과 텍스트

이벤트는 "cmd:arg0:arg1" 형태 문자열 + 값으로 옵니다. 예: 버튼 ev:"del:3" → e.cmd=="del", e.argInt(0)==3.

4. 전체 예시 — “AI 메모”

메모를 저장(storage)하고, 목록을 사이드바에 보여주고, 버튼으로 AI 요약(generate)하는 완결형 플러그인입니다. 아래 코드는 실제로 컴파일·검증되었습니다.

import { JSON } from "assemblyscript-json/assembly";
import * as ui from "./aisummary";
import { Node } from "./aisummary";

// 마샬링 re-export
export function alloc(s: i32): usize { return ui.alloc(s); }
export function dealloc(p: usize, s: i32): void { ui.dealloc(p, s); }

// 상태
let notes: string[] = [];
let draft: string = "";
let output: string = "";

// 렌더 — 선언적으로
function render(): void {
  const main: Node[] = [
    ui.Text("💡 AI 메모"),
    ui.Textarea(draft, "메모를 입력…", "draft"),
    ui.Row([
      ui.Button("＋ 저장", "add", "primary"),
      ui.Button("✨ AI로 요약", "summarize"),
    ]),
  ];
  if (output.length > 0) main.push(ui.Markdown(output));
  ui.renderMain(main);

  const side: Node[] = [ ui.Text("메모 " + notes.length.toString() + "개", true) ];
  for (let i = 0; i < notes.length; i++) {
    const preview = notes[i].length > 40 ? notes[i].substring(0, 40) : notes[i];
    side.push(ui.Card("note-item", [
      ui.Text(preview),
      ui.Button("삭제", "del:" + i.toString(), "mini danger"),
    ]));
  }
  ui.renderSidebar(side);
}

// 라이프사이클
export function on_init(ptr: usize, len: i32): void {
  const store = ui.initStorage(ptr, len);
  notes = [];
  const arr = store.getArr("notes");
  if (arr != null) { const a = arr.valueOf();
    for (let i = 0; i < a.length; i++) notes.push((<JSON.Str>a[i]).valueOf()); }
  render();
}

export function on_event(hp: usize, hl: i32, pp: usize, pl: i32): void {
  const e = ui.event(hp, hl, pp, pl);
  if (e.cmd == "draft") { draft = e.value; return; }        // 텍스트: 리렌더 X
  if (e.cmd == "add") {
    if (draft.length == 0) { ui.toast("내용을 입력하세요"); return; }
    notes.push(draft); draft = "";
    ui.storage.saveStrings("notes", notes); ui.toast("저장됨"); render(); return;
  }
  if (e.cmd == "del") {
    const idx = e.argInt(0); const n: string[] = [];
    for (let k = 0; k < notes.length; k++) if (k != idx) n.push(notes[k]);
    notes = n; ui.storage.saveStrings("notes", notes); render(); return;
  }
  if (e.cmd == "summarize") {
    if (notes.length == 0) { ui.toast("메모가 없습니다"); return; }
    output = "…"; render();
    ui.generate(1, "다음 메모들을 3줄로 요약해줘:\n- " + notes.join("\n- "),
                 "너는 간결한 메모 정리 도우미야.");
    return;
  }
}

export function on_generate_done(reqId: i32, ptr: usize, len: i32): void {
  output = ui.readStr(ptr, len); render();
}

5. 빌드 & 배포

asc src/main.ts -o plugin.wasm --optimize --exportRuntime --lib ./node_modules

산출된 plugin.wasm + plugin.json을 폴더째 넣으면 끝입니다.

  • 사용자 설치: ~/.aisummary/plugins/<id>/에 폴더 복사 → 설정에서 켜기
  • 배포: 완성된 plugin.wasm을 그대로 공유(앱은 소스를 받지 않고 바이너리만 로드). npm 패키지가 dist/를 올리는 것과 같은 모델
assemblyscript-json 패치 필요. 이 라이브러리의 Str.stringify()는 제어문자(줄바꿈) 이스케이프에 버그가 있어, 줄바꿈이 든 텍스트를 저장하면 깨집니다. 빌드 전 node_modules/assemblyscript-json/assembly/JSON.ts의 Str.stringify()가 \n \r \t를 올바로 이스케이프하도록 한 번 고치세요(자세한 스니펫은 BUILD.md). SDK 내부의 esc()는 이미 안전합니다.

6. 테스트 (Node 하네스)

앱 없이도 Node로 wasm을 직접 구동해 로직을 검증할 수 있습니다. 호스트 import를 목(mock)으로 채우고 export를 호출하면 됩니다.

import fs from "fs";
const bytes = fs.readFileSync("plugin.wasm");
let ex, mem; const dec = new TextDecoder(), enc = new TextEncoder();
const rd = (p,l) => dec.decode(new Uint8Array(mem.buffer, p, l));
const env = {
  abort: () => { throw new Error("abort"); },
  host_ui_render: (p,l) => console.log("UI:", rd(p,l)),
  host_toast: (p,l) => console.log("toast:", rd(p,l)),
  host_storage_save: (p,l) => console.log("save:", rd(p,l)),
  host_generate: (r,p,l) => console.log("gen:", rd(p,l)),
  host_storage_delete(){}, host_export(){}, host_preview(){}, host_log(){},
};
const { instance } = await WebAssembly.instantiate(bytes, { env });
ex = instance.exports; mem = ex.memory;
const w = s => { const b = enc.encode(s); const p = ex.alloc(b.length);
  new Uint8Array(mem.buffer, p, b.length).set(b); return [p, b.length]; };
// 초기화 후 이벤트 흘려보내기
{ const [p,l] = w(JSON.stringify({ storage: { notes: ["첫 메모"] } })); ex.on_init(p,l); ex.dealloc(p,l); }
import는 env 하나로 충분. SDK가 @external("env", …)로 모든 호스트 함수를 env 모듈에 고정하므로, 목 객체 하나만 바인딩하면 됩니다.

7. 함정 (자주 걸리는 것)

  • 텍스트 입력 리렌더 금지 — Input/Textarea 핸들러에서 render()하면 포커스가 튑니다. 상태만 갱신하세요.
  • 이벤트 값의 출처 — 인덱스 같은 인자는 핸들러 문자열("del:3")에, 입력 값은 e.value에 옵니다. 둘을 혼동하지 마세요.
  • JSON 라이브러리 패치 — §5 경고 참고. SDK의 esc()·storage.*는 안전하지만, JSON.Obj.stringify()를 직접 쓰면 패치가 필요합니다.
  • 결정성 — WASM에는 시계·난수가 기본 없습니다. 필요하면 상태로 관리하거나 카운터를 쓰세요.
  • 메모리 — 호스트에 넘기는 문자열은 SDK가 인코딩합니다. 직접 포인터를 다룰 때만 alloc/dealloc을 신경 쓰세요.
  • abort — 잘못된 캐스트/배열 범위 초과는 wasm을 abort시킵니다. 호스트는 이를 try/catch로 잡아 앱이 죽지 않게 하지만, 로직에서 방지하는 게 최선입니다.

8. 체크리스트

  • ✅ alloc/dealloc을 export 했는가 (SDK 위임)
  • ✅ on_init/on_event/on_generate_done export
  • ✅ plugin.json에 entry + code:wasm, network:false
  • ✅ 텍스트 입력 핸들러는 상태만 갱신(리렌더 X)
  • ✅ 저장은 storage.*로 격리 폴더에만
  • ✅ assemblyscript-json 패치 적용 후 빌드
  • ✅ Node 하네스로 라이프사이클 검증
